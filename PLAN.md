# CS106 — Web Foundations (HTML/CSS) — PLAN

**Semester:** 1 · **Credits:** 3 · **Level:** Beginner
**Theory:** 30 hrs · **Lab:** 30 hrs · **Tools:** VS Code, browser, GitHub Pages

## Syllabus

### Unit 1 — How the Web Works (5 lectures)
1. Client, server, request-response
2. URLs — scheme, host, path, query
3. HTTP methods and status codes (overview)
4. Static vs dynamic content
5. How a browser renders a page

### Unit 2 — HTML (10 lectures)
1. Document structure — doctype, head, body
2. Semantic elements — header, nav, main, footer, article, section
3. Headings and paragraphs
4. Links — anchors, internal, external, mailto
5. Images and figures
6. Lists — ordered, unordered, definition
7. Tables — proper use and semantic markup
8. Forms — inputs, labels, buttons, validation
9. Media — audio, video, iframe
10. Accessibility — alt text, ARIA basics, contrast

### Unit 3 — CSS Fundamentals (10 lectures)
1. What CSS is — cascade, specificity, inheritance
2. Selectors — element, class, ID, pseudo-class, pseudo-element
3. The box model — margin, border, padding, content
4. The display property — block, inline, inline-block, flex
5. Colors, backgrounds, and gradients
6. Typography — fonts, weights, line-height
7. Units — px, em, rem, %, vh, vw
8. Positioning — static, relative, absolute, fixed, sticky
9. Flexbox — layout in one dimension
10. CSS Grid — layout in two dimensions

### Unit 4 — Responsive Design and Deployment (5 lectures)
1. Media queries
2. Mobile-first design
3. Responsive images
4. CSS frameworks overview (Bootstrap, Tailwind)
5. Deploying with GitHub Pages

## Practical Labs (18)

1. Set up VS Code and folder structure
2. Your first HTML page
3. Semantic page structure — a blog post
4. A navigation bar
5. Images and figures with alt text
6. Lists — recipe page
7. Tables — a schedule
8. A contact form with validation
9. Audio/video embedding
10. Accessibility audit of your page
11. First stylesheet — colour and typography
12. Box-model playground
13. Flexbox navbar
14. Flexbox cards layout
15. CSS Grid gallery
16. Responsive layout with media queries
17. Mobile-first redesign of a previous lab
18. Deploy your site on GitHub Pages

4. Responsive blog layout
